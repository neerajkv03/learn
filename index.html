Chapter 06

Closures

A closure is a function bundled with references to the variables around it. It lets a function remember where it was created, even after that scope has finished running.

  • Level Intermediate
  • Read time 8 min
  • Updated Nov 2026

What is a closure?

Every function in JavaScript keeps a hidden link to its lexical environment, the set of variables that were in scope where the function was defined. When the function runs later, it reads those variables through that link.

  • Closures are created every time a function is created.
  • They capture variables, not values. Changes are visible.
  • Captured variables live as long as the closure does.
Note

Scope is decided by where code is written, not where it is called. That is what "lexical" means.

Common pitfalls

Warning

Using var in a loop shares one variable across all iterations. Every callback sees the final value.

Memory

Closures keep their captured variables alive. Long-lived closures holding large objects (event listeners, caches) can leak memory. Remove listeners you no longer need.

Summary

Key takeaway

A closure is a function plus the variables it was born next to. Use it for private state and factories; use let in loops.
